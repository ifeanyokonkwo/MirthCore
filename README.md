# MirthCore

MirthCore is a scalable, message-centric engine for real-time data processing and event-driven routing, leveraging stream-based architecture.

MirthCore is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/MirthCore.git`
2. `cd MirthCore`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
